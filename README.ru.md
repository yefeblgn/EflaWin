# Эфла Вин

**Diller / Languages:** [TR](README.md) · [EN](README.en.md) · [ES](README.es.md) · [RU](README.ru.md) · [DE](README.de.md) · [中文](README.zh.md) · [日本語](README.ja.md)

Efla Win собирает загрузки приложений, управление драйверами и часто используемые настройки системы в одном окне при настройке нового компьютера с Windows. Разработано с использованием WinUI 3.

## Начало

Откройте файл `Efla Win 1.0.0.exe` в 64-разрядной версии Windows 11 и дайте одобрение администратору. Никакого установочного пакета не требуется. Компоненты .NET и Windows App SDK включены в EXE-файл и открываются в локальном кэше при первом запуске. Для загрузки и сканирования Центра обновления Windows требуется подключение к Интернету.

### Загрузка и установка приложений

1. Начните с **Рекомендуется** или выберите категорию на экране **Все приложения**. **Ctrl+F** фокусирует поле поиска.
2. Для одного приложения используйте кнопку **Загрузить**. Чтобы поставить несколько в очередь, установите флажки рядом с логотипом и нажмите кнопку **Загрузить выбранное**.
3. По умолчанию загруженные файлы записываются в каталог `Efla Win` в папке «Загрузки» Windows. Вы можете выбрать другую папку, нажав **Изменить** на нижней панели, и просмотреть файлы, нажав **Открыть папку**.
4. После завершения загрузки кнопка **Установить** откроет установщик. Когда Windows сообщает, что приложение установлено, появляется кнопка **Удалить**, и после ее подтверждения открывается инструмент удаления приложения.

Опция **Открыть исходный код** в контекстном меню карточки открывает страницу распространения в каталоге.

### Отслеживайте загрузки и просмотр

**Доступные действия** в левом меню показывают очередь загрузки и сканирование драйверов, даже если вы переключаете страницы. Появится объем данных, полученных при загрузке. Если сервер сообщает общий размер, он также будет показан. Кнопка ****** рядом с процессом останавливает это задание.

Когда окно свернуто, оно переходит в область уведомлений. Вы можете открыть окно, папку загрузки или экран памяти из контекстного меню значка Efla Win. **Выход** закрывает приложение.

### редактировать окна

| Экран | Что ты можешь сделать? |
| --- | --- |
| **Настройки Windows** | Проверьте параметры поиска, панели задач, конфиденциальности, производительности и проводника. Перейдите на страницы запуска приложений, хранилища, сети и прокси-сервера. |
| **Настройки игры** | Ознакомьтесь с игровым режимом, фоновой записью и опциями игровой панели Xbox. Откройте графические настройки и план электропитания. |
| **Аппаратное обеспечение** | Посмотрите свой процессор, видеокарту, версию Windows, использование оперативной памяти и свободное место на диске. |
| **Драйверы** | Основные инструменты Intel, AMD и NVIDIA, основанные на устройстве. Найдите драйверы, предлагаемые в Центре обновления Windows, и откройте экран **Дополнительные обновления** для установки. |
| **Память** | Посмотрите текущее использование оперативной памяти. **Очистить**, чтобы сократить количество рабочих наборов подходящих приложений в этом сеансе. |
| **Настройки приложения** | Система регулирует светлую или темную тему, цвет подсветки, размер шрифта, жирный текст, контрастность и уменьшение движения. |

Если рядом с параметром указано **Заблокировано**, кнопка информации показывает политику и путь сохранения, которые применяет Windows. **Недоступно** означает, что этот параметр не поддерживается данной версией Windows или компьютером. Некоторые настройки отображаются только при повторном входе в систему.

## Скомпилировать из исходников

.NET 10 SDK и Windows SDK должны быть установлены в Windows. Откройте исходный архив и запустите PowerShell в папке, содержащей файл `EflaWin.csproj`.

```powershell
dotnet publish .\EflaWin.csproj -c Release -p:PublishSingleFile=true -p:IncludeAllContentForSelfExtract=true -p:EnableCompressionInSingleFile=true
```

Выходные данные широковещательной рассылки находятся по пути `bin\Release\net10.0-windows10.0.19041.0\win-x64\publish\EflaWin.exe`. Этого EXE достаточно для распространения.

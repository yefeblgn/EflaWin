# エフラウィン

**Diller / Languages:** [TR](README.md) · [EN](README.en.md) · [ES](README.es.md) · [RU](README.ru.md) · [DE](README.de.md) · [中文](README.zh.md) · [日本語](README.ja.md)

Efla Win は、新しい Windows コンピューターをセットアップするときに、アプリケーションのダウンロード、ドライバー制御、頻繁に使用されるシステム設定を 1 つのウィンドウにまとめます。 WinUI3で開発しました。

## 始まり

64 ビット Windows 11 で `Efla Win 1.0.0.exe` ファイルを開き、管理者の承認を与えます。インストールパッケージは必要ありません。 .NET および Windows App SDK コンポーネントは EXE に含まれており、初回実行時にローカル キャッシュに解凍されます。ダウンロードと Windows Update スキャンにはインターネット接続が必要です。

### アプリをダウンロードしてインストールする

1. **推奨**から始めるか、**すべてのアプリ**画面でカテゴリを選択します。 **Ctrl+F** は検索ボックスにフォーカスを当てます。
2. 単一のアプリの場合は、[**ダウンロード**] ボタンを使用します。いくつかをキューに入れるには、ロゴの横にあるボックスをチェックし、**選択したものをダウンロード** ボタンを押します。
3. デフォルトでは、ダウンロードされたファイルは Windows のダウンロード フォルダーの `Efla Win` ディレクトリに書き込まれます。下部バーの **変更** で別のフォルダーを選択し、**フォルダーを開く** でファイルを表示できます。
4. ダウンロードが完了したら、**インストール** ボタンをクリックしてインストーラーを開きます。 Windows がアプリケーションがインストールされていると報告すると、[**アンインストール**] ボタンが表示され、確認後にアプリケーションの削除ツールが開きます。

カードの右クリック メニューにある **オープン ソース** オプションを選択すると、カタログ内の配布ページが開きます。

### ダウンロードと閲覧を追跡する

左側のメニューの **利用可能なアクション** には、ページを切り替えてもダウンロード キューとドライバー スキャンが表示されます。ダウンロード時の受信データ量が表示されます。サーバーが合計サイズを報告する場合は、それも表示されます。プロセスの横にある ****** ボタンは、そのジョブを停止します。

ウィンドウを最小化すると、通知領域に移動します。 Efla Winアイコンの右クリックメニューからウィンドウ、ダウンロードフォルダ、メモリ画面を開くことができます。 **終了** はアプリケーションを閉じます。

### 編集ウィンドウ

| 画面 | 何ができるでしょうか？ |
| --- | --- |
| **Windows の設定** | 検索、タスクバー、プライバシー、パフォーマンス、ファイル エクスプローラーのオプションを確認します。スタートアップ アプリ、ストレージ、ネットワーク、プロキシのページに移動します。 |
| **ゲーム設定** | ゲーム モード、バックグラウンド録画、Xbox ゲーム バーのオプションを確認してください。グラフィック設定と電源プランを開きます。 |
| **ハードウェア** | プロセッサー、グラフィックス カード、Windows のバージョン、RAM の使用量、ディスクの空き容量を確認します。 |
| **ドライバー** | デバイスに基づいて Intel、AMD、NVIDIA ツールを強調表示します。 Windows Update で提供されるドライバーをスキャンし、**オプションの更新** 画面を開いてインストールします。 |
| **メモリ** | 現在の RAM 使用量を確認します。 **パージ**して、このセッションの対象となるアプリケーションのワーキング セットを減らします。 |
| **アプリケーション設定** | システムは、明るいテーマまたは暗いテーマ、ハイライトカラー、フォントサイズ、太字テキスト、コントラスト、モーションリダクションを調整します。 |

設定の横に **ロック** と表示されている場合、情報ボタンには Windows が適用するポリシーと保存パスが表示されます。 **利用不可** は、そのオプションがこのバージョンの Windows またはコンピュータでサポートされていないことを示します。一部の設定は再ログインしないと反映されません。

## ソースからコンパイルする

.NET 10 SDK および Windows SDK が Windows にインストールされている必要があります。ソース アーカイブを開き、`EflaWin.csproj` ファイルが含まれるフォルダーで PowerShell を実行します。

```powershell
dotnet publish .\EflaWin.csproj -c Release -p:PublishSingleFile=true -p:IncludeAllContentForSelfExtract=true -p:EnableCompressionInSingleFile=true
```

ブロードキャスト出力はパス `bin\Release\net10.0-windows10.0.19041.0\win-x64\publish\EflaWin.exe` にあります。配布にはこの EXE で十分です。

## フィードバック

エラーを報告する場合は、Windows のバージョン、エラーが発生した画面、および繰り返す手順を含めてください。ダウンロードの問題の場合は、アプリ名とカードに表示されるエラー テキストも含めてください。 EFLAKEEP000トークン
